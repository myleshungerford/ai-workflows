# Loose Ends

The assistant holding the session context performs this audit. Do not delegate it to a reviewer who cannot see what was skipped. Limit it to a named work item when the user specifies one.

Ask:

- What am I least confident about in the work we just did?
- What consequential limitation might the user not realize?

Each item must name a specific session action or shortcut, the possible consequence, and an observable check that would settle it. Include the uncomfortable omission that reflects your own incomplete work. Do not pad the list with generic risks.

Run cheap, safe, authorized checks now. For a check requiring substantial new work or unavailable access, report the next step and estimated effort without implying it was performed. If evidence refutes a concern, close it rather than retaining a stale caveat.

Keep findings ordered by impact:

- **Loose end:** What was skipped or assumed, and where.
- **Why it matters:** The concrete result that could change.
- **Check and result:** What was run and observed, or what remains to run.

A concern is a hypothesis until checked. Distinguish a failed check from a check not run or one impossible with the current evidence. "Nothing material found" is valid. If session context is incomplete, disclose that limit rather than claiming a complete audit.
